# Commands

Loom adds five Artisan commands, which read or write one index, by default `storage/loom/index.json`.

```bash
php artisan loom:scan                    # scan the app and write the index
php artisan loom:show OrderPlaced        # print the index, filtered
php artisan loom:diff old.json new.json  # compare two indexes
php artisan loom:check                   # run the policy rules
php artisan loom:mcp                     # serve the index over MCP
```

## loom:scan

```bash
php artisan loom:scan [--output=PATH] [--path=DIR ...] [--route-path=DIR ...] [--allow-empty] [-v]
```

Parses the app without booting it, validates the result against the [schema](schema.md) and writes the index. The directories come from [scan configuration](scan-config.md).

| `--path=` | Scan this directory instead of `scan.paths`. Relative to the project root; glob patterns allowed. Repeatable. |

| `--allow-empty` | Write an index even when the scan directories hold no PHP files, instead of failing. |

It prints the path written, the files read and a count per section. `-v` also lists each skipped file with its parser message and each route-file path not followed, with its reason:

## loom:show

```bash
php artisan loom:show [filter]
```

Prints the index as pretty JSON.

<!-- generated:command:loom:show -->
<!-- Generated by `just docs-generate`; edit the source, not this block. -->

| Argument | Meaning |
| --- | --- |
| `filter` | Optional substring (a class or method name); keeps only events, listeners, observers and `model_events` entries whose JSON text contains it. |
<!-- /generated:command:loom:show -->

The filter matches each entry's JSON text in events, listeners, observers and model events; other sections print in full. A filter with `/` or `\` never matches, because the JSON escapes them.

Exit `0` when printed, `1` when the index is missing, unreadable or not valid JSON.

## loom:diff

```bash
php artisan loom:diff old.json new.json --format=markdown
```

Compares two indexes by entry: added, removed and changed, not a text diff.

## loom:check

```bash
php artisan loom:check [index] --strict --baseline=main-index.json
```

Runs the policy rules against an index and fails when one is violated.

<!-- generated:command:loom:check -->
<!-- Generated by `just docs-generate`; edit the source, not this block. -->

| Argument or option | Meaning |
| --- | --- |
| `index` | Path to the index to check (default: `storage/loom/index.json`). |
| `--baseline=` | Path to an older `index.json`, for growth checks. |
| `--strict` | Treat any unresolved dispatch as a failure. |
| `--skip=` | Rule key to skip. Repeatable. |
| `--format=` | Output format: text (default), json or markdown. |
<!-- /generated:command:loom:check -->

Rules, exit codes and formats are in [Check rules and formats](check-rules-and-formats.md).

## loom:mcp

```bash
php artisan loom:mcp
```

Starts a read-only [MCP](https://modelcontextprotocol.io) server over stdio that serves the index and reloads it when the file changes. [MCP tools](mcp-tools.md) lists what it answers.

<!-- generated:command:loom:mcp -->
<!-- Generated by `just docs-generate`; edit the source, not this block. -->

| Option | Meaning |
| --- | --- |
| `--snapshot=` | Serve this index file instead of the default (`storage/loom/index.json`); it is never auto-scanned. |
| `--scan` | Run `loom:scan` before serving; cannot be combined with `--snapshot`. |
| `--no-scan` | Never auto-scan; the snapshot must already exist. |
| `--allow-empty` | Pass `--allow-empty` to `loom:scan` when this command scans. |
<!-- /generated:command:loom:mcp -->

Exit `0` when the server stops normally, `1` when `laravel/mcp` isn't installed, `mcp.enabled` is `false`, the scan before serving fails or the server isn't registered.

Every config key is in [Index, UI and MCP configuration](ui-config.md) and [Scan configuration](scan-config.md).
